# СтройКуб — учебный инженерный проект

Сайт включает каталог, страницы товаров, калькуляторы, сравнение материалов, нормативный справочник, тест, корзину, избранное и личный кабинет.

## Публикация

Загрузите все файлы в корень публичного репозитория GitHub и включите GitHub Pages.

## Важно

Расчёты учебные и предварительные. Для реального проектирования используйте актуальные нормативные документы, проектную документацию и данные производителей.
