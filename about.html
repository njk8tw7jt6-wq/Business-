О проекте

Учебный веб-проект по подбору, расчёту и сравнению строительных материалов.

Цель проекта

Создать демонстрационный веб-сервис для систематизации информации о строительных материалах, выполнения предварительных расчётов и анализа нормативных требований.

Исходные данные

  • Перечень материалов и их характеристики.
  • Ориентировочные цены и единицы измерения.
  • Нормативные документы: ГОСТ и СП.
  • Типовые геометрические параметры для расчётов.

Методика

  • Формирование каталога материалов.
  • Указание нормативных документов.
  • Разработка калькуляторов, включая расчёт армирования плиты.
  • Сравнение материалов по ключевым параметрам.
  • Сохранение расчётов и избранных материалов.
  • Реализация корзины и личного кабинета.

Выводы

Сайт позволяет систематизировать информацию, выполнить предварительные расчёты, сравнить материалы и сохранить результаты. Проект демонстрирует применение HTML, CSS и JavaScript для создания инженерного справочника.

Ограничения

Расчёты являются учебными и предварительными. Для реального проектирования необходимы актуальные нормативные документы, проектная документация, данные производителей и расчёт по действующим СП.
